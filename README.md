# Settlers of Java

**Author:** Evan Feng, Danny Toy  
**Java Version:** Java 25.0.2

## Overview
Settlers of Java is a digital and object-oriented implementation of the board game *Catan*. This project uses Java and JavaFX to recreate the core mechanics of the game.
